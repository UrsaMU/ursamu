+TIME

  In-game date, clock, season, weather, moon, and sun
  for a London-like climate. Uses game layout chrome.

SYNTAX
  +time

NOTES
  Clock is 12-hour. Moon phase follows the 28-day month.
  Weather is stable for several hours, then can shift.
  Staff set the clock with **@time**.

EXAMPLES
  +time

SEE ALSO: +help ic, +help cofd
