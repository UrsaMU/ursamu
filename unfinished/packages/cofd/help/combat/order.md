combat/order  -- Reading the initiative table and turn order.


SEE ALSO: help combat (overview)., help DISPLAY,
help +combat/order shows each participant in descending init order:,
help Name      Init  HP      Status, help Jax       14    OOO...  (active),
help Marcus    11    OOOOO., help HP boxes: O healthy, help / bashing,
help X lethal, help * aggravated., help '!' next to name = Beaten Down.,
help TURN FLOW,
help Highest init acts first. /next ends the current turn; any following,
help NPCs act via AI until a PC (or a manual NPC) is up. After the last,
help actor, help the round counter loops and Defense resets. /next/manual,
help advances one slot with no AI., help DELAY / DROP,
help /delay pushes your action later; /act reclaims., help Reaching 0 HP,
help Immobilized, help or /leave removes you from rotation., help combat,
  help combat/initiative, help combat/delaying
