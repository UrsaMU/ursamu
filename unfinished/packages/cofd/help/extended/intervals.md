+EXTENDED INTERVALS  -- Narrative time per attempt.

INTERVALS (display only; no real-time gate)
  turn   Combat turn. hour  Research/craft.
  day    Major projects. scene  Default.

SYNTAX
  +extended/start <pool>=<target>/<max>/<interval>
  e.g. +extended/start wits+invest=8/4/hour dig

DEFAULTS
  Interval: scene. Max rolls: Resolve+Composure.

SEE ALSO: help extended, help extended/contested
