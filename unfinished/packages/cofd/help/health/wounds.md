+HEALTH WOUNDS  -- Track size, cascade, penalties.

TRACK
  Size = Stamina + Size. Boxes: / X * for B/L/A.

CASCADE
  Fill free boxes; heavier upgrades lighter when full.

WOUND PENALTY
  Rightmost three boxes: −1 / −2 / −3 (worst only).

STATES
  All bashing → unconscious. All lethal → dying.
  All aggravated → dead.
