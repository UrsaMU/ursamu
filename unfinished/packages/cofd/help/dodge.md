+DODGE  -- Defense and dodging (reference; no +dodge cmd).

MECHANICS
  Spend instant action to double Defense as a pool vs
  one attack. Each success cancels one attack success.
  Only when Defense applies (not Firearms).

MULTIPLE ATTACKERS
  −1 Defense per extra attacker, then double.
  Defense 0 before double → chance die.

WILLPOWER
  +2 Defense vs one attacker (before doubling).

INCOMPATIBLE
  Cannot attack same turn; no All-Out or Charge.

SEE ALSO: help combat, help attack, help grapple
