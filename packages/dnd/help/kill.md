+KILL

Execute an unconscious monster for XP and a lootable corpse.

SYNTAX
  +kill [<target>]

NOTES
  Target must be Monster at 0 HP. No arg uses focus.
  Same name matching as +attack (partial, 2.name, #id).
  Finishing +attack also auto-kills at 0 HP.

EXAMPLES
  +kill 2.goblin
  +kill #142
  +kill
  +loot corpse of orc

SEE ALSO: +help attack, +help focus, +help loot
