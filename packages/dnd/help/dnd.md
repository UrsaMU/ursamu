Character Sheet & Rules Plugin
------------------------------------------------------------------------------
This plugin implements support for character stats, rolling, and health tracking
within UrsaMU.

COMMANDS
  +cg         - Guided character generation wizard.
  +sheet      - View or edit your character sheet.
  +roll       - Roll ability/skill checks, saving throws, or custom dice formulas.
  +hp         - Track and modify hit points (current, max, and temporary). (Alias: +health)

GETTING STARTED
  1. Start character creation by running: +cg
  2. Set your basic traits (class, species, background) in Stage 1.
  3. Set your ability scores in Stage 2.
  4. Finalize your character sheet with: +cg/submit
  5. View your sheet with: +sheet
  6. Roll checks with: +roll Strength or +roll Stealth

SEE ALSO: help cg, help sheet, help roll, help hp
