+ALTAR

Touch altars or campfires found in delves.

SYNTAX
  use <name>
  +altar [touch] <name>

NOTES
  Prefer the core **use** verb. Each works once. Altars
  heal 1d8; campfires restore 5 HP. `+altar` is a thin
  alias.

EXAMPLES
  use Dusty Altar
  use Cookfire

SEE ALSO: +help adventure, +help hp
