+FOCUS

Sticky combat target for +attack and +kill.

SYNTAX
  +focus [<target>]
  +focus clear

TARGET
  Same matching as +attack: partial names,
  2.name ordinals, or #dbref. +combat/status
  shows each foe as Name(#id).

EXAMPLES
  +focus gob
  +focus 2.goblin
  +focus #142
  +attack
  +focus clear

SEE ALSO: +help attack, +help kill
