+IP

Award Improvement Points to an edgerunner after a run. Admin only.

SYNTAX
  +ip <target>=<amount>

EXAMPLES
  +ip Rogue=5       Award 5 IP to Rogue after tonight's run.
  +ip Johnny=3      Award 3 IP to Johnny.

  Standard award is 1-5 IP per run. Both the current IP pool and
  the lifetime IP total are updated. The target edgerunner receives
  a notification when IP is awarded.

SEE ALSO: +help improve
