+THERAPY

Medtech/admin **recalibration** to cut Humanity Loss.
Success: 2d6 HL back. Crisis buys temporary EMP, not full fix.

SYNTAX
  +therapy[/switch] [<target>]

SWITCHES
  /status [<target>]   HL, EMP, and session DV.
  /session [<target>]  Run a therapy session.
  /crisis <target>     Emergency cyberpsychosis aid.

EXAMPLES
  +therapy/status Rogue     Check Rogue's HL.
  +therapy/session Rogue    Run a session.
  +therapy/crisis Patient   Crisis intervention.

SEE ALSO: +help humanity, +help cyber
