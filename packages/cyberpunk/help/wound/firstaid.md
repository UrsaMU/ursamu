+FIRSTAID

Patch up a nearby edgerunner before they bleed out.

Uses TECH + First Aid (DV15) or TECH + Paramedic (DV13). If you
have any Paramedic skill, it kicks in automatically.

On success, restores 1d6 HP and updates their wound state.
Can't patch yourself, and flatlined edgerunners are beyond
first aid.

SYNTAX
  +firstaid <target>

EXAMPLES
  +firstaid Rogue       Attempt to patch up Rogue.
  +firstaid Johnny      Attempt to patch up Johnny.

SEE ALSO: +help wound/stabilize, +help wound, +help wound/deathsave
