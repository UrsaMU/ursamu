+CHARGEN/METHOD

Pick how you build STATs and skills.

SYNTAX
  +chargen/method <streetrat|edgerunner|complete>

METHODS
  streetrat   Book templates — 1d10 STAT row + fixed skills.
  edgerunner  Roll STATs; spend 86 pts on Role skills (2–6).
  complete    Full point-buy (62 STAT / 86 skill points).

EXAMPLES
  +chargen/method streetrat
  +chargen/method complete

SEE ALSO: +help chargen, +help chargen/stats
