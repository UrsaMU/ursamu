+CHARGEN/DONE

Submit for staff approval, or wipe a sheet (wizard+).

SYNTAX
  +chargen/done
  +chargen/reset <name>
  +cprreset <name>
  +wipe <name>

NOTES
  `/done` only at review (needs concept notes).
  `/reset` is wizard+ — wipes draft **or approved** sheet
  so they can run `+chargen` again. Same as `+cprreset`
  and `+wipe`.

EXAMPLES
  +sheet                Preview before submit.
  +chargen/done         Submit for staff approval.
  +chargen/reset Sable  (Wizard+) Wipe Sable's sheet.
  +wipe Sable           Same wipe.

SEE ALSO: +help chargen, +help sheet, +help +approve
