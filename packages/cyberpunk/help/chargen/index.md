+CHARGEN

Guided Cyberpunk RED character creation wizard.

SYNTAX
  +chargen[/<switch>] [<argument>]

SWITCHES
  /method <streetrat|edgerunner|complete>  Method.
  /role <role>                  Pick role.
  /roll|/detail|/next           Lifepath controls.
  /stat|/skill <k>=<n>          Allocate points.
  /lifestyle|/chrome|/gear      Loadout stages.
  /done                         Finalize.
  /reset                        (Admin) Wipe draft.

EXAMPLES
  +chargen/method streetrat   Start streetrat path.
  +chargen/role solo          Choose Solo.
  +chargen/done               Lock in and play.

SEE ALSO: +help chargen/method, +help chargen/done
