+CYBER

Install and manage **cyberware**. HL lowers EMP.

SYNTAX
  +cyber[/switch] [<argument>]

SWITCHES
  /list [cat]     Browse catalog by category.
  /view           Your installed chrome.
  /install <name> Install (Medtech/admin).
  /remove <name>  Remove chrome.

EXAMPLES
  +cyber/list neuralware
  +cyber/install neural_link
  +cyber/view
