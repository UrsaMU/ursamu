+CHOPSHOP

Ripperdoc queue: harvest and install chrome for others.

SYNTAX
  +chopshop[/switch] [<argument>]

SWITCHES
  /queue              Your install queue.
  /install <t>=<cw>   Install chrome on target.
  /harvest <t>=<cw>   Extract chrome from target.
  /shop ...           Stall management (see game).

EXAMPLES
  +chopshop/install Rogue=cybereye
  +chopshop/harvest CorpSec=subdermal_armor

SEE ALSO: +help cyber, +help humanity
