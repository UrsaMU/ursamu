+INIT

Roll initiative and get in line — combat starts now.

If no fight is running, this kicks one off. Once everyone's
rolled, check the queue to see who goes when.

Roll formula: REF + 1d10 + modifier + wound penalty.
**Kerenzikov** cyberware adds +2. **Sandevistan** adds +3 (once).

SYNTAX
  +init [<modifier>]

EXAMPLES
  +init           Roll REF + 1d10 for initiative.
  +init +2        Roll with a +2 situational modifier.
  +init -1        Roll with a -1 modifier.

SEE ALSO: +help combat, +help combat/pass
