+THROW / +GRENADE

Lob a grenade or thrown explosive.

SYNTAX
  +throw <target|point> [with <grenade>]
  +grenade <target|point> [with <grenade>]

NOTES
  Uses Athletics. AoE radius and save depend on the item.

EXAMPLES
  +throw Rogue with frag
  +grenade doorway with flashbang

SEE ALSO: +help attack, +help combat
