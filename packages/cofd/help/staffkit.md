+STAFFKIT

Staff-only one-shot splat kit so game locks pass without
full chargen. For testing hedge, harvest, fae look, etc.

SYNTAX
  +staffkit <splat> [<target>]
  +staffkit/<splat> [<target>]
  +staffkit/list
  +staffkit/clear [<target>]

SPLATS
  changeling   Lost sheet, approved, fae, Glamour full.

EXAMPLES
  +staffkit changeling
  +staffkit/changeling me
  +staffkit/clear

SEE ALSO: +help hedge, +help perception, +sheet
