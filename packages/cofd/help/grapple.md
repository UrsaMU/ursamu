+GRAPPLE  -- Start or continue a grapple (CoFD 2e).

SYNTAX
  +grapple <target>              Initiate grapple.
  +grapple/<move> [<target>]     Use a grapple move.
  +grapple/break                 Struggle free.

PERMISSIONS
  Connected; must be in or starting an encounter.

MOVES
  See help grapple/moves for hold, damage, take-down,
  disarm, and firearm-in-grapple rules.

EXAMPLES
  +grapple Marcus
  +grapple/damage
  +grapple/break

SEE ALSO: help grapple/moves, help grapple/firearms,
  help combat, help attack
