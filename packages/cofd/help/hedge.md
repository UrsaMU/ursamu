+HEDGE  -- Portaling, travel, goblin fruit (CtL 2e).

SYNTAX
  +hedge                 Realm, gates, fruit, path.
  +hedge/open [<name>]   Portal (1 Glamour if closed).
  +hedge/exit [<name>]   Leave via a linked gate.
  +hedge/travel <goal>   Navigate (chase vs the Hedge).
  +hedge/forage          Harvest fruit (Wits+Survival).
  +hedge/fruit [catalog] Satchel or full catalog.
  +hedge/eat <slug>      Eat a carried fruit.
  +hedge/claim           Claim an unclaimed Hollow.

DUAL LOOK
  Gates default to "Strange passage" for mortals;
  **fae** sees the true gate name. Room flavor /
  maskflavor on +hedge status. See help perception.
