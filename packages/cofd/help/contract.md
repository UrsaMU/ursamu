+CONTRACT  -- List or invoke a Changeling Contract.

SYNTAX
  +contract                  List Contracts on sheet.
  +contract/list             Same.
  +contract/info <name>      Catalog detail + loophole.
  +contract/loophole <name>  Invoke; waive Glamour cost.
  +contract/learn <name>     Spend XP to learn a Contract.
  +contract/grant <p>=<name> Staff: Grant directly.
  +contract <name>           Invoke (pay cost; roll).
  +contract <name> on <t>    Inflict hooks on a target.

RULES
  Court learn gates use Mantle / Court Goodwill merits.
  Royal Arcadian need a favored Regalia. Goblin Contracts
  add 1 Goblin Debt on learn. Loopholes waive Glamour only
  (WP still paid). Matching seeming clauses print on invoke.
  Mantle is a valid dice-pool trait for court Contracts.
  Mien down: successes promote to exceptional (Wyrd floor).
  Named Conditions/Tilts in effect text auto-apply on
  success (self-buffs, or on <target> when inflicted).

EXAMPLES
  +contract/learn Chrysalis
  +contract/loophole Hostile Takeover
  +contract Paralyzing Presence on Bob
  +contract Tale of the Baba Yaga on Alice
