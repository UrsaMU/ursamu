+SPIN  -- Hedgespinning: reshape the Hedge (CtL).
SYNTAX
  +spin                      Effect catalog.
  +spin/list                 Same.
  +spin/info <effect>        Effect detail.
  +spin <effect> [text]      Attempt (costs Glamour).
  +spin/path | /shelter | /barrier | /veil
  +spin/fruit | /trap
EFFECTS
  path      +2 next travel (~1h). 1G, need 2.
  shelter   Safer room (trod-like). 2G, need 3.
  barrier   Thorn wall (RP/ST). 2G, need 3.
  veil      Set maskFlavor. 1G, need 2.
  fruit     Coax common fruit. 2G, need 3.
  trap      Snare (ST). 2G, need 3.
NOTES
  Hedge or Hollow only. Pool: Wits + Crafts or
  Occult (higher) + Wyrd.
