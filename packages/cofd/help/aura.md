+AURA  -- Project Predatory Aura (VtR).

SYNTAX
  +aura                              List flavors.
  +aura <flavor> <target>            Contest vs target.
  +aura/project <flavor>=<target>    Same, explicit form.

FLAVORS
  hungry → Bestial     awe → Charmed
  wrath  → Cowed       terror → Wanton
  predator → Competitive

Pool: Presence + Intimidation + Blood Potency vs
Composure + BP (vampires) or Composure (+ power stat).

SEE ALSO: help frenzy, help condition, help vampire
