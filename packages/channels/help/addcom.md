+ADDCOM

  Join a channel by setting a short alias for it.

SYNTAX
  addcom <alias>=<channel>

  Both the alias and channel name are case-sensitive. You can join
  the same channel with multiple aliases, though this can be confusing.

EXAMPLES
  addcom pub=Public
  addcom st=Staff

SEE ALSO: +help delcom, +help comtitle, +help comlist, +help clearcom
