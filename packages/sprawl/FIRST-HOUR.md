# First hour — Sprawl Goons

0. Browse help and tables anytime (no draft needed):
   `+help sprawl`, `+chargen/list backgrounds`,
   `+chargen/info nodejacker`, `+help combat`.
1. `+chargen` — status panel lists the five stats and steps.
2. `+chargen/start` — open a draft.
3. Spend **4** points (0–4 each): MOR melee, EQU nerve,
   REA guns/drive, COG hack/sense, AFF talk/con.
   Example: `+chargen/stat reaction=2` then COG/AFF =1.
4. `+chargen/background roll` (or pick a slug).
5. `+chargen/belongings roll` three times — each becomes a
   real carried Thing (uses rolled when the book says so).
6. `+chargen/cash` — 2d6 × 100 b¥.
7. Optional: `+chargen/quirk roll`, `+chargen/affect roll`.
8. `+chargen/submit` — opens a **CGEN** job (and mail).
   Staff: `+chargen/approve <name>`, or close the CGEN job
   in `+jobs` / web jobs UI (same as CofD).
9. `+sheet` / `inv` — Res 12 / Loadout score / carried gear.
10. `@desc me=…` (or `+desc/roll`) for the base look; then
   `inv`, `wear #1`, `wield #2` — gear weaves in live.
   Help: `+help wear`.
11. `use yeheyuan` (or your pack) — charges go down.
12. `+roll reaction/10` — first Action Roll.
13. `+attack 10` — dangerous fight vs DS10 goon.
14. Nodejacker path (optional):
    `+market console` → `+market/buy hyperion` →
    `+console/buy tunnel-rat` → `+hack 12` →
    `+exploit` / `+exploit/use 1`.
15. Street contract: `+gig` → `+gig/enter` →
    `+attack` / `+hack` → `+gig/push` → `+gig/turnin`.
16. Help deep-dives: `+help combat/examples`,
    `+help hack/examples`, `+help gig/examples`.
17. `+flow districts` — pick a place to run.

Currency is **b¥**. `>>` is a sparse status accent, not every line.
Gear is object-based: `get` / `drop` / `give` / `use` / `inv`.
