+HACK/BUY

See also: +help hack (overview)

SYNTAX
  +market console|software|net-hw
  +market/buy <#>|slug
  +console/buy <slug>

RULES
  Console buy equips. Software buy loads
  (need deck + free slots).

EXAMPLES
  +market console
  +market/buy hyperion
  +console/buy tunnel-rat
  +market/buy flipper-zero

SEE ALSO: +help market, +help hack/console
