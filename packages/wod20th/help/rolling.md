WOD20TH-ROLLING -- Dice Rolling

  See also: +help wod20th (overview)

SYNTAX
  +roll <pool>              Roll a numeric dice pool.
  +roll <trait>[+<trait>]   Roll using character traits.
  +roll/spec <pool>         Roll with specialty (10s re-roll).

EXAMPLES
  +roll 5                   Roll 5 dice.
  +roll Strength+Athletics  Roll Strength + Athletics pool.
  +roll/spec Dexterity      Roll Dexterity with specialty.

SEE ALSO: +help wod20th, +help chargen
