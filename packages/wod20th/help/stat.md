+STAT

  View or directly set a character stat (staff only).

SYNTAX
  +stat <target>/<trait>=<value>   Set a stat on a character.
  +stat <target>/<trait>           View a stat value.

  Bypasses chargen step gating. Changes are written to the audit log.
  Requires admin+ flag.

EXAMPLES
  +stat Alice/Strength=4       Set Alice's Strength to 4.
  +stat Bob/gnosis=3           Set Bob's Gnosis to 3.
  +stat Carol/concept=Hunter   Set Carol's concept text.

SEE ALSO: +help sheet, +help wod20th
