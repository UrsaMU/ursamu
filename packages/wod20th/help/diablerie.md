DIABLERIE -- Amaranth

  See also: +help vtm (overview)

  Drain a helpless Kindred's heart-blood. Lowers generation
  if the victim is lower gen; always stains the aura.

SYNTAX
  +diablerie <victim>         Commit Amaranth.
  +diablerie/confirm <victim> Same (explicit).

NOTES
  Victim must be Incapacitated or in torpor.
  Always runs a path check (heinous killing).
  Assamites roll Self-Control vs vitae addiction.
  Same room required unless staff.

EXAMPLES
  +diablerie Rook

SEE ALSO: +help humanity, +help feed, +help torpor, +help vtm
