SPIRIT -- Garou spirit catalog

  The spirit DB lists totems, gafflings, jagglings, incarnae, and the
  great celestines. Stats are Rage / Gnosis / Willpower / Power. Each
  entry has Charms and a Ban (taboo).

SYNTAX
  +spirit                       List the whole catalog.
  +spirit/list [<type>]         List spirits; optional type filter.
  +spirit/info <slug>           Show full sheet (stats, charms, ban).
  +spirit/totems                Shortcut for +spirit/list totem.

SWITCHES
  /list      Types: totem, gaffling, jaggling, incarna, celestine,
             wyrm, weaver, wyld.

EXAMPLES
  +spirit/list totem
  +spirit/info wolf
  +spirit/info grandfather-thunder

SEE ALSO: +help spirit-interact, +help pack, +help fetish
