HELP -- wod20th topic index

  Liberation-style two-column index of plugin topics.
  Prefer +help in-game (same content, live catalog).

SYNTAX
  +help                     Full index by category.
  +help <topic>             Show a topic file.
  +help/section <name>      One category only.
  +help/index               Same as bare +help.

EXAMPLES
  +help
  +help vtm
  +help blood
  +help/section Vampire

SEE ALSO: +help vtm, +help chargen, +help pack
