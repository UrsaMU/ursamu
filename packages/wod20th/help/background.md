BACKGROUND -- W20 Backgrounds catalog

  Browse-only catalog of the W20 Backgrounds chapter (W20 Ch 3). The
  Background dots themselves are still purchased through +stat / +xp;
  this command exists so players can read dot ladders and tribe gating
  without flipping books.

SYNTAX
  +background                 List all Backgrounds.
  +background/list            Same as +background.
  +background/info <slug>     Show one Background's dot ladder and notes.

EXAMPLES
  +background/info pure-breed
  +background/info ancestors
  +background/info totem

NOTES
  Tribe restrictions are flagged on the listing for reference only;
  enforcement (if any) happens via tribe definitions at chargen time.

SEE ALSO: +help chargen, +help xp, +help pack
