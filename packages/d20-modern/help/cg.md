+CG

Guided character generation wizard for d20 Modern.

SYNTAX
  +cg[/<switch>] [<args>]

SWITCHES
  /set    Set a value in the current stage (e.g. `class=strong`).
  /list   List available options (occupations, skills, feats).
  /next   Go to the next stage. /back goes to the previous.
  /reset  Reset chargen state. /submit finalizes sheet.

EXAMPLES
  +cg
  +cg/set occupation=academic
  +cg/next
