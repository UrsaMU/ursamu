+BBS

Full-featured in-game Bulletin Board System (BBS) plugin.

GROUPS
  Type `+help bbs/<group>` to view commands in each category:

  reading      — List boards, topics, and read posts.
  posting      — Draft, preview, post, and edit messages.
  groups       — Subscribe to boards and manage notifications.
  management   — Edit, sticky, move, flag, and delete posts.
  staff        — Board creation, locks, and system config.

SEE ALSO: +help bbs/reading, +help bbs/posting, +help bbs/groups
