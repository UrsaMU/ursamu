+BBS/STAFF

Staff administration — board setup and locks.

COMMANDS
  Type `+help <cmd>` or `+help bbs/staff/<cmd>`:

  bbnewgroup    Create a board
  bbanon        Anonymous authors on/off
  bbcleargroup  Mark board for deletion
  bbconfirm     Confirm board deletion
  bblock        Set read lock
  bbwritelock   Set write lock
  bbtimeout     Post expiry (days)
  bbcategory    Display category
  bbwebhook     Discord webhook URL
  bbconfig      Global BBS settings

SEE ALSO: +help bbs, +help bbs/management
