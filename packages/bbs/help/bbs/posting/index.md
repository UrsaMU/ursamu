+BBS/POSTING

Draft, preview, post, and edit messages.

COMMANDS
  +bbpost[/ic|/ooc] [<#>/<subct>[=<body>]] — Post or start a draft.
  +bb <text>                               — Append text to draft.
  +bbproof                                 — Preview your current draft.
  +bbtoss                                  — Discard your current draft.
  +bbreply[/ic|/ooc] <#>/<post>[=<text>]   — Reply to a post.
  +bbedit <#>/<post>[.<rep>][=<old>/<new>] — Inline edit a post/reply.
  +bbsig [<text>]                          — Manage your message signature.
  +bbtag [<tag1>[,<tag2>...]]              — Set tags on draft.
  +bblink <#>/<post>[=<sceneId>]           — Link a scene to a post.

SEE ALSO: +help bbs (overview)
