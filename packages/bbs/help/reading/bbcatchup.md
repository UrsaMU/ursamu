+BBCATCHUP

Mark board(s) as fully read without displaying them.

SYNTAX
  +bbcatchup [<#>|all]

  No args or `all`: mark every board read.
  `<#>`: mark one board fully read.

EXAMPLES
  +bbcatchup 2    Mark board 2 as read.
  +bbcatchup all  Mark all boards as read.

SEE ALSO: +help bbs/reading, +help bbnext
