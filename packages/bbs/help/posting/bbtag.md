+BBTAG

Set tags on your current BBS draft.

SYNTAX
  +bbtag [<tag1>[,<tag2>...]]

  No args clears tags. Tags are searchable
  with +bbsearch <#>/tag:<name>.

EXAMPLES
  +bbtag lore,history    Set two tags.
  +bbtag                 Clear all tags.

SEE ALSO: +help bbs/posting, +help bbsearch
