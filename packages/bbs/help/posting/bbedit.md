+BBEDIT

Inline edit a post or reply you own (or any
post if you are a board mod or staff).

SYNTAX
  +bbedit <#>/<post>[.<reply>][=<old>/<new>]

  With `<old>/<new>`: find-and-replace once.
  Without: load the post into your draft.

EXAMPLES
  +bbedit 2/3=typo/fixed
  +bbedit 2/3.1=typo/fixed
  +bbedit 2/3

SEE ALSO: +help bbs/posting, +help bbpost
