+BBNOTIFY

Toggle new-post notifications for a board.

SYNTAX
  +bbnotify <#>=<on|off>

  Default is on for joined boards. Off
  silences new-post broadcasts only.

EXAMPLES
  +bbnotify 2=on     Enable notifications.
  +bbnotify 2=off    Disable notifications.

SEE ALSO: +help bbs/groups, +help bbjoin
