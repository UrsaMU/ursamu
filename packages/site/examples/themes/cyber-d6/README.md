# CYBER d6 theme

Installable `@ursamu/site` skin. Tokens are copied 1:1 from
`cyber-d6/src/theme/tokens.ts` (the React Native app) onto
`--site-*`.

Phosphor teal on near-black. Courier New. 1px line borders.
Zero radius. No decorative art.

| Task | Command |
|------|---------|
| Preview | `deno task preview:open` |
| Theme Studio | `deno task studio` |
| Pack zip | `deno task pack` |

```bash
cd packages/site/examples/themes/cyber-d6
deno task preview:open
deno task pack
```

Upload `cyber-d6.zip` in **Admin → Settings → Public site**.

Visual editor: https://github.com/UrsaMU/theme-studio
