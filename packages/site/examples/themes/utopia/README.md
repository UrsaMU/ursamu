# Utopia RetroWave theme

Installable public FE theme for the Utopia pinned deck.

Hot pink / purple / navy mapped onto `--site-*`. Glow stays on
the masthead, SEND, and ruling packets — not every surface.

## Commands

```bash
deno task studio
deno task pack
```

Upload `utopia.zip` in **Admin → Settings → Public site**.

See `packages/site/design.md` §4a for layout types.
