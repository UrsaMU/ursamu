+OEMIT

  Send a message to everyone in a room except one object
  (often the actor). Useful in action code and scripts.

SYNTAX
  @oemit <target>=<message>

  Target is excluded from the room broadcast.

EXAMPLES
  @oemit me=Alice leaves quietly.
  @oemit #5=The door slams.
