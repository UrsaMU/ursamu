+ACTIONS

  Attribute hooks that run on get, look, move, and use.
  Also @oemit for private messages in a room.

TOPICS
  **overview**  When action attrs fire
  **get**       Get / give related
  **look**      Look-time hooks
  **move**      Enter / leave / move
  **object**    Object-centric hooks
  **use**       @use and USE attributes
  **oemit**     Emit to others, not actor

SEE ALSO: +help locks, +help building
