+USE

  Trigger an object's use action when the engine provides
  @use / USE attributes.

SYNTAX
  @use <object>

  Locks (use lock) still apply. Without a use action the
  command may fail quietly or with a default message.

EXAMPLES
  @use Lever
  @use Button

SEE ALSO: +help locks/types, +help actions/overview
