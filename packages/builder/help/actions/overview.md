+OVERVIEW

  Action attributes are named text/softcode on objects. The
  engine runs them when a matching event happens (get, look,
  move, use). Fail messages use FAIL / OFAIL / AFAIL with locks.

NOTES
  Keep code short. Prefer locks for access control.
  See subtopics for attribute names per event.

SEE ALSO: +help actions/get, +help actions/use
