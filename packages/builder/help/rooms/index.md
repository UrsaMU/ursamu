+ROOMS

  Create rooms and exits, then link destinations.

COMMANDS
  **dig**      Create a room (optional exits).
  **open**     Create exits from here.
  **link**     Set exit destination or home.
  **unlink**   Clear a link.

  Costs quota unless you are staff. Exit names may use
  `Name;alias` form (example: `North;N`).

SEE ALSO: +help building, +help objects/quota
