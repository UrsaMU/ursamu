+LINK

  Set where an exit goes, or set a player's/object's home.
  Requires canEdit on the target.

SYNTAX
  @link <exit>=<destination>
  @link <player|thing>=<home room>
  @link me=here

EXAMPLES
  @link North=#20
  @link me=here
  @link Widget=#5

SEE ALSO: +help rooms/unlink, +help rooms/open
