+SET

  Set flags or attribute values on an object you can edit.
  Exact switches depend on the installed set script.

SYNTAX
  @set <target>=<flag>
  @set <target>=!<flag>
  @set <target>/<attr>=<value>

EXAMPLES
  @set here=DARK
  @set me=!DARK
  @set Widget/FOO=bar

SEE ALSO: +help attrs/attr, +help attrs/wipe
