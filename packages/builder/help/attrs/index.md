+ATTRS

  Set and manage attributes on objects.

COMMANDS
  **set**       @set flags or simple attrs (see topic).
  **attr**      &ATTR / @setattr style notes.
  **formats**   NAMEFORMAT DESCFORMAT CONFORMAT EXITFORMAT.
  **wipe**      Remove matching attributes.

  Softcode and sandbox scripts may also set attrs. Prefer
  `$set` via the engine when writing plugins.

SEE ALSO: +help building, +help locks
