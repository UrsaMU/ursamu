+FORMATS

  Look uses format attributes when set. Clear by setting empty.

SYNTAX
  @nameformat <target>=<code>
  @descformat <target>=<code>
  @conformat <target>=<code>
  @exitformat <target>=<code>

  `%0` is the default text for that slot when evaluated.

EXAMPLES
  @nameformat here=%ch%0%cn
  @descformat me=
