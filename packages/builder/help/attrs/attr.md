+ATTR

  Object attributes store text, softcode, or data. Names are
  usually UPPERCASE. Use examine to list them.

NOTES
  Hidden attrs may be staff-only. Locks can block read/write.
  Format slots (NAMEFORMAT, etc.) control look layout.

EXAMPLES
  @examine me
  @set here/DESC=A quiet hall.

SEE ALSO: +help attrs/formats, +help objects/examine
