+MONIKER

  Set a display name (may include color codes). Plain text
  of a player moniker must not match another player's login
  name. Lock: admin+.

SYNTAX
  @moniker <target>=<display>

EXAMPLES
  @moniker Alice=%chAlicia%cn
  @moniker #5=The Old Wizard

SEE ALSO: +help objects/name
