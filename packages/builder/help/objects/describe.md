+DESCRIBE

  Set the description shown by look. Alias: @desc.
  Requires canEdit.

SYNTAX
  @desc <target>=<description>
  @describe <target>=<description>

EXAMPLES
  @desc me=A tall figure in dark robes.
  @desc here=A cozy room lit by firelight.

SEE ALSO: +help objects/name, +help attrs/formats
