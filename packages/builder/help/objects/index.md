+OBJECTS

  Create and manage things, names, descriptions, and quota.

COMMANDS
  **create**    Make a thing in inventory.
  **destroy**   Delete an object (not players).
  **clone**     Copy an object and its attributes.
  **chown**     Transfer ownership (admin+).
  **name**      Rename (players must be unique).
  **describe**  Set description (@desc).
  **moniker**   Display name (admin+).
  **parent**    Attribute inheritance parent.
  **examine**   Full object dump.
  **quota**     View or set build quota.

SEE ALSO: +help building, +help rooms
